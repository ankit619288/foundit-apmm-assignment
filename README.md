# foundit Talent Operations Assistant

This project was built for the foundit APMM AI & Automation take-home assignment.

It includes:
- A Streamlit talent-supply agent using the provided India IT/ITeS data
- An automated fRL winner calculation workflow
- A dashboard for talent overview and winner review
- Notes for the system prompt, test Q&A, fRL method, and bonus winner.py analysis

Run locally:

```powershell
python -m pip install -r requirements.txt
python run_pipeline.py
python -m streamlit run src/app.py
```
